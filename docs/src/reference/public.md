# Public API Reference

```@meta
CurrentModule = PowerNetworkMatrices
```

This page is the exhaustive, autogenerated index of every **exported** symbol in
`PowerNetworkMatrices`. Docstrings are sourced directly from the code, so they
are always authoritative — the sparsification tolerance, network-reduction,
contingency, and serialization details all live here, in the docstrings, rather
than in a separate prose page. For narrative context and worked examples, follow
the links:

  - [Matrix Overview](network_matrices_overview.md) and the [matrix type reference](matrix_types.md)
  - [How to Define and Apply Contingencies](../how_to_guides/generated_contingencies.md)
  - [How to Choose a Linear Solver](../how_to_guides/generated_choose_linear_solver.md)

Every exported symbol appears **exactly once** below. Non-exported symbols that
ship with a docstring are collected in the final section for completeness; they
are not part of the supported API. Internal solver submodules are documented
separately under [Internals](internals.md).
